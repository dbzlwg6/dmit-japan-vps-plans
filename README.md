## 延迟到底多少：两组口径不同的数据

第三方测评站汇总的口径是：电信到上海约 60–80ms，联通到北京约 50–65ms，移动到广州约 50–60ms。作为对照，同配置的洛杉矶节点平均在 150–180ms。

另一份单人单点的电信宽带测评给出的数字是：工作日白天稳定在 75–85ms，晚高峰没有超过 120ms；同一个人测普通日本 VPS，晚高峰能从 80ms 飙到 200ms 以上。

两组数据对不上，因为测试时间、工具、本地线路、目标节点都不一样。汇总数据看起来更漂亮，单人数据更接近普通用户的实际体感。把 60ms 当成承诺值去验收，大概率会失望；把 120ms 当上限，反而更接近真实。

横向看，DMIT 香港 Premium 到大陆主要城市通常在 50ms 以内，日本 Premium 在 60–80ms 区间，但日本套餐比香港便宜，还给日本原生 IP。香港缺货的时候，日本是最接近的替代。
